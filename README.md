# 📢 Ad Cards Web Application

A responsive web application developed with **.NET Core**, **Angular**, and **PostgreSQL**, designed to display and manage advertisement cards.

---

## 🚀 Features

- **Home Page** – Public view of advertisement cards  
- **Login Page** – Secure authentication for authorized users  
- **Dashboard** – Restricted area for managing ads  
- **CRUD Operations** – Create, update, and delete advertisement cards  
- **Authorization** – Only authenticated users can access management features  
- **Responsive Design** – Optimized for mobile and desktop screens  

---

## 🛠 Tech Stack

- **Backend:** .NET Core Web API  
- **Frontend:** Angular  
- **Database:** PostgreSQL  

---

## 📌 Overview

This project demonstrates a modern **full-stack architecture** with secure authentication, clean separation of concerns, and a responsive user interface suitable for real-world applications.
